Image Resizer — frontend prototypes

Six independent HTML/CSS/JS takes on the same backend (upload → configure N output sizes → poll for results). Every control the API exposes — resize mode, quality, upscale, multiple sizes per request — is tweakable in each variant, and every output image opens full-size in a shared lightbox. Open one, poke at it, then use the tab bar at the top of any variant to hop between them without losing your place.

🎛️

Sidebar Studio

Persistent left sidebar for upload + global defaults, a scrollable list of size "rows" you add/remove, live results panel on the right. Good for power users iterating on many sizes at once.

Guided Wizard

Step-by-step flow: upload → build sizes as cards → review → submit → watch status. Friendlier for first-time or occasional users, one decision at a time.

Dashboard Cards

Power / Raw JSON

A compact form mirrors a live-editable raw JSON payload — for people who'd rather type the sizes array directly than click sliders. Great for probing edge cases and validation errors.

Preset Picker

Big one-click tiles for common shapes (thumbnail, avatar, social, hero…) — each just a pre-filled tweakable size. An "advanced" drawer still exposes raw mode/quality/upscale/custom sizes underneath.

Every output gets a draggable before/after slider against the original — the fastest way to judge whether a crop mode grabbed the wrong region or quality dropped too far.
